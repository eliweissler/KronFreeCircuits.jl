# Tutorial: two coupled zero-pi qubits

This tutorial solves two zero-pi qubits coupled through their charges, a six-mode circuit whose full Hilbert space would be far too large to diagonalize directly.
It builds a three-level tree, reads the coupled spectrum, and plots the two-dimensional wavefunctions of each qubit's `(θ, φ)` leaf.

## The circuit

The spec was generated by circuit-quantization from the lumped circuit: two symmetric zero-pi qubits, each with two junctions, two large inductors and two large capacitors, coupled capacitively through two coupler islands.

```@example tzp
using KronFreeCircuits, CairoMakie
CairoMakie.activate!(type="png") # hide
figdir = mkpath(joinpath(pkgdir(KronFreeCircuits), "docs", "build", "tutorials")) # hide

spec = load_spec("two_zero_pi.json")
[(m.name, m.type) for m in spec.modes]
```

Each qubit (`1` or `2`) has three modes, named with its number (`theta1`, `phi1`, `zeta1`, ...):

- `theta`, compact (`:c`): half the difference of the two junction phases, which are `θ + φ` and `−θ + φ`; its offset charge is `n_g1` (or `n_g2`);
- `phi`, extended (`:e`): the junctions' common phase, which the inductors confine;
- `zeta`, harmonic (`:h`): an oscillator that decouples from the junctions in the symmetric circuit.

The coupling `g` enters as a charge-charge term between `theta_1` and `theta_2`.
The parameters, in GHz (with the flux `varphi_ext` in radians):

```@example tzp
qubit(q) = (Symbol("E_J$q") => 10.0, Symbol("E_L$q") => 0.04, Symbol("E_CJ$q") => 20.0, Symbol("E_CS$q") => 0.5,
            Symbol("varphi_ext$q") => 2π * 0.23, Symbol("n_g$q") => 0.1)
θ = (; qubit(1)..., qubit(2)..., g=0.05)
```

## The tree

A tree that follows the physics:

```
                 root  (couples the qubits through g)
               /                    \
        qubit 1                      qubit 2
       /       \                    /       \
 (θ₁, φ₁)       ζ₁           (θ₂, φ₂)       ζ₂
  leaf          leaf           leaf          leaf
```

- The `(θ, φ)` leaf diagonalizes the two strongly coupled modes of one qubit together, in a charge basis for θ and a phase grid for φ, and keeps its 10 lowest states.
- The `ζ` leaf is an oscillator in a Fock basis. Its zero-point width comes from the spec's charging and inductive energies.
- Each qubit node combines its two leaves, and the root couples the qubits.

```@example tzp
function zpf(spec, mode, θ)                       # zero-point phase width of a harmonic mode
    i = findfirst(m -> m.name === mode, spec.modes)
    return (2real(spec.E_C[i, i](θ)) / real(spec.E_L[i, i](θ)))^(1 / 4)
end

leaf(q) = Node([Symbol("theta$q") => ChargeBasis(15), Symbol("phi$q") => PhaseGrid(-10π, 10π, 501)];
               compute=10, keep=lowest(10))
zeta(q) = Node([Symbol("zeta$q") => FockBasis(20; phi_zpf=zpf(spec, Symbol("zeta$q"), θ))]; keep=lowest(3))
qubits = [Node([leaf(q), zeta(q)]; keep=lowest(10)) for q in 1:2]
root = Node(qubits; keep=lowest(12))
nothing # hide
```

Each `(θ, φ)` leaf has 31 × 501 = 15 531 product states.
The φ grid spans ±10π because the kept states spread over several wells of the inductive potential: on a narrower grid `materialize` warns that a kept state reaches the grid's edges.

## Solving

```@example tzp
sys, records = KronFreeCircuits.node_timings(() -> materialize(root, spec, θ))
[(modes=r.modes, dim=r.dim, solver=r.solver, kept=r.kept) for r in records]
```

`Auto()` picked `ShiftInvert` for the large leaves and `Dense` for everything else.
Every node runs in real arithmetic (see [Real arithmetic](../manual/real_arithmetic.md)):

```@example tzp
unique(arithmetic(sys, n) for n in (root, qubits..., qubits[1].children...))
```

## The spectrum

The coupled levels, relative to the ground state:

```@example tzp
E = energies(sys)
round.(E .- E[1]; digits=5)
```

One qubit's own levels, read at its node:

```@example tzp
Eq = energies(sys, qubits[1])
round.(Eq .- Eq[1]; digits=5)
```

The qubit's lowest transition is about 0.25 GHz, and its ζ oscillator adds a ladder at 0.39 GHz.
In the coupled spectrum the qubit excitations come in near-degenerate pairs, one per qubit, split by the coupling.
`dressed_state_string` shows each dressed state's content in the two qubits' kept states, with physics indices from 0:

```@example tzp
for n in 0:3
    println(dressed_state_string(sys, n))
end
```

## Wavefunctions of a leaf

The `(θ₁, φ₁)` leaf of qubit 1 holds the qubit's states before the ζ mode and the coupling are added.
Its wavefunctions are two-dimensional:

```@example tzp
leaf1 = qubits[1].children[1]
grids, ψ = phase_wavefunction(sys, leaf1)
length(grids.theta1), length(grids.phi1), size(ψ)
```

Their probability densities, `|ψ(θ, φ)|²`, for the four lowest leaf states.
The potential's wells alternate along φ between `θ = 0` and `θ = ±π`, and each state spreads over several of them.
In the phase picture the two lowest states look almost alike: their densities overlap strongly, and the difference between them is not visible here.

```@example tzp
Eleaf = energies(sys, leaf1)
window = abs.(grids.phi1) .<= 4π
fig = Figure(size=(900, 520))
for s in 1:4
    ax = Axis(fig[(s - 1) ÷ 2 + 1, (s - 1) % 2 + 1]; xlabel="φ / π", ylabel="θ / π",
              title="state $(s - 1),  E - E₀ = $(round(Eleaf[s] - Eleaf[1]; digits=4)) GHz")
    heatmap!(ax, grids.phi1[window] ./ π, grids.theta1 ./ π, abs2.(ψ[:, window, s])'; colormap=:viridis)
end
save(joinpath(figdir, "zero_pi_phase.png"), fig); nothing # hide
```

![Phase densities of the four lowest leaf states](zero_pi_phase.png)

The same states with θ in its charge representation, `|ψ(n_θ, φ)|²`, where they separate.
The ground state has most of its weight on `n_θ = 0` and the first excited state on `n_θ = ±1`:

```@example tzp
grids_n, ψn = phase_wavefunction(sys, leaf1; charge=:theta1)
fig = Figure(size=(900, 520))
for s in 1:4
    ax = Axis(fig[(s - 1) ÷ 2 + 1, (s - 1) % 2 + 1]; xlabel="φ / π", ylabel="n_θ", title="state $(s - 1)")
    heatmap!(ax, grids_n.phi1[window] ./ π, grids_n.theta1, abs2.(ψn[:, window, s])'; colormap=:viridis)
    ylims!(ax, -6, 6)
end
save(joinpath(figdir, "zero_pi_charge.png"), fig); nothing # hide
```

![The same states with θ in charge](zero_pi_charge.png)

The fraction of each state's weight on those charges:

```@example tzp
weight(s, ns) = sum(abs2, ψn[findall(in(ns), grids_n.theta1), :, s]) / sum(abs2, ψn[:, :, s])
(ground_on_0=weight(1, (0,)), excited_on_pm1=weight(2, (-1, 1)))
```

## The ζ oscillator

A Fock basis has no grid, so its wavefunctions take points:

```@example tzp
ζ = range(-14, 14; length=561)
_, ψζ = phase_wavefunction(sys, qubits[1].children[2], ζ)
fig = Figure(size=(700, 350))
ax = Axis(fig[1, 1]; xlabel="ζ", ylabel="ψ(ζ)")
for s in 1:3
    lines!(ax, ζ, real.(ψζ[:, s]); label="state $(s - 1)")
end
axislegend(ax)
save(joinpath(figdir, "zeta_oscillator.png"), fig); nothing # hide
```

## Sweeping the coupling

The coupling `g n_θ1 n_θ2` exchanges an excitation between the qubits through the matrix element of `n_θ` between each qubit's two lowest states.
Each qubit node forms that charge port, since the root needs it to build the coupling:

```@example tzp
n01 = port(sys, :theta1, nport(), qubits[1])[1, 2]
(matrix_element=abs(n01), predicted=2 * θ.g * abs2(n01), solved=E[3] - E[2])   # splitting 2 g |n₀₁|² vs E₂ − E₁
```

The matrix element is small because `n_θ` does not change the charge, and the two states live on nearly disjoint charges (even and odd `n_θ`, above).
So the exchange splitting is only about 3 kHz, and the first-order estimate matches the solved splitting to within 1%.
`previous=sys` passes the last solution on to the next point of a sweep:

```@example tzp
gs = [0.0, 0.025, 0.05, 0.1]
splitting = map(gs) do g
    s = materialize(root, spec, merge(θ, (g=g,)); previous=sys)
    E = energies(s)
    E[3] - E[2]
end
fig = Figure(size=(600, 350))
ax = Axis(fig[1, 1]; xlabel="g (GHz)", ylabel="E₂ − E₁ (GHz)", title="splitting of the first excited pair")
scatterlines!(ax, gs, splitting)
save(joinpath(figdir, "coupling_sweep.png"), fig); nothing # hide
```

![Splitting of the first excited pair against g](coupling_sweep.png)
