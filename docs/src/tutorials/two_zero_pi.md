# Tutorial: two coupled soft zero-pi qubits

This tutorial solves the two capacitively coupled soft zero-pi qubits of Liu, Weissler and Combes, *Two-qubit gates for the soft 0-π qubit*, [arXiv:2609.16630](https://arxiv.org/abs/2609.16630).
It builds a three-level tree, reads the coupled spectrum and the static ZZ rate, checks how both converge with the truncation, and sweeps the coupling capacitance through the level crossings the paper discusses.
Following the paper, the circuit has no disorder, so only the θ and φ modes of each qubit take part.

## The circuit

The spec was generated by circuit-quantization from the paper's circuit (a): two symmetric zero-pi qubits, each with two junctions, two superinductors, two large capacitors and a capacitance `C_0` from each node to ground, coupled through two coupler islands that connect to all four nodes of each qubit.

```@example tzp
using KronFreeCircuits, CairoMakie
CairoMakie.activate!(type="png") # hide
figdir = mkpath(joinpath(pkgdir(KronFreeCircuits), "docs", "build", "tutorials")) # hide

spec = load_spec("two_soft_zero_pi.json")
[(m.name, m.type) for m in spec.modes]
```

Each qubit (`1` or `2`) has three modes, named with its number:

- `theta`, compact (`:c`): half the difference of the two junction phases, which are `θ + φ` and `−θ + φ`; its offset charge is `n_g1` (or `n_g2`);
- `phi`, extended (`:e`): the junctions' common phase, which the inductors confine;
- `zeta`, harmonic (`:h`): an oscillator that decouples exactly in the symmetric circuit.

The parameters are the paper's Table I, in GHz: qubit 1 is the device of Gyenis et al. (see [Tutorial: a soft zero-pi qubit](@ref)), and qubit 2 has its `E_J` lowered by 10%.
`E_Ctheta` and `E_Cphi` are the charging energies of the uncoupled qubit, `E_Cc` that of each coupling capacitor and `E_C0` that of each ground capacitor:

```@example tzp
θ = (E_Ctheta=0.092, E_Cphi=1.14, E_Cc=1.0, E_C0=1.491, E_L=0.377, E_J1=6.013, E_J2=5.412,
     n_g1=0.0, n_g2=0.0, varphi_ext1=0.0, varphi_ext2=0.0)
nothing # hide
```

The coupler renormalizes each qubit's charging energies and adds the coupling `g n_θ1 n_θ2`, with `g = 8 E_C[θ1, θ2]`.
The spec reproduces the paper's values: E_C^θ drops by about 4% and E_C^φ by about 50%, and g ≈ 0.031 GHz:

```@example tzp
EC = [real(spec.E_C[i, j](θ)) for i in 1:4, j in 1:4]          # theta1, phi1, theta2, phi2
(E_Ctheta=EC[1, 1], E_Cphi=EC[2, 2], g=8EC[1, 3])
```

## The tree

```
                 root  (couples the qubits through g)
               /                    \
        qubit 1                      qubit 2
       /       \                    /       \
 (θ₁, φ₁)       ζ₁           (θ₂, φ₂)       ζ₂
  leaf          leaf           leaf          leaf
```

- The `(θ, φ)` leaf diagonalizes the two strongly coupled modes of one qubit together, θ in a charge basis and φ on a phase grid, and keeps its `k` lowest states.
- Without disorder `ζ` is exactly decoupled. Its leaf keeps only its ground state, which removes it from the spectrum as the paper's two-mode model does.
- Each qubit node combines its two leaves, and the root couples the qubits.

```@example tzp
function zpf(spec, mode, θ)                       # zero-point phase width of a harmonic mode
    i = findfirst(m -> m.name === mode, spec.modes)
    return (2real(spec.E_C[i, i](θ)) / real(spec.E_L[i, i](θ)))^(1 / 4)
end

function tree(k; root_keep=30)
    leaf(q) = Node([Symbol("theta$q") => ChargeBasis(20), Symbol("phi$q") => PhaseGrid(-8π, 8π, 401)];
                   compute=k + 4, keep=lowest(k))
    zeta(q) = Node([Symbol("zeta$q") => FockBasis(8; phi_zpf=zpf(spec, Symbol("zeta$q"), θ))]; keep=lowest(1))
    qubits = [Node([leaf(q), zeta(q)]; keep=lowest(k)) for q in 1:2]
    return Node(qubits; compute=root_keep, keep=lowest(root_keep)), qubits
end
nothing # hide
```

Each leaf has 41 × 401 = 16 441 product states, and the root `k²`.
A root larger than 1000 states is solved iteratively, so it states how many eigenpairs to `compute`.

## The spectrum

With `k = 20` states per qubit:

```@example tzp
root, qubits = tree(20)
sys, records = KronFreeCircuits.node_timings(() -> materialize(root, spec, θ))
[(modes=r.modes, dim=r.dim, solver=r.solver, kept=r.kept) for r in records]
```

Qubit 1's own levels, read at its node, include the renormalization by the coupler:

```@example tzp
E1 = energies(sys, qubits[1])
round.(E1[1:11] .- E1[1]; digits=4)
```

The logical states are `|0_L⟩ = |0⟩`, the ground state of the θ = 0 valley, and `|1_L⟩ = |2⟩`, the lowest state of the θ = π valley; `|1⟩` is a θ excitation in the θ = 0 valley.
`dressed_state_string` shows each dressed state's content in the two qubits' kept states, with physics indices from 0:

```@example tzp
for n in 0:4
    println(dressed_state_string(sys, n))
end
```

The non-logical `|1⟩` excitations of the two qubits are close in energy, and the coupling mixes them; the logical states have disjoint support, and `|0,2⟩` is barely dressed.

## Static ZZ and truncation

The static ZZ rate compares qubit 1's logical transition with qubit 2 in `|0⟩` and in `|2⟩`:
`ZZ = (E_{2,2} − E_{0,2}) − (E_{2,0} − E_{0,0})`.
It comes from virtual transitions through higher qubit states, so it depends on how many states each qubit keeps.
`dressed_index` finds the dressed state with the largest weight on a product of the qubits' kept states (1-based):

```@example tzp
function zz(sys, root)
    E = energies(sys)
    i(l) = dressed_index(sys, root, l)
    return (E[i((3, 3))] - E[i((1, 3))]) - (E[i((3, 1))] - E[i((1, 1))])
end

map((20, 40, 80, 120)) do k
    r, _ = tree(k)
    (k=k, ZZ_Hz=round(1e9 * zz(materialize(r, spec, θ), r); digits=1))
end
```

The rate converges to a magnitude of 171 Hz, the value the paper gives.
Because the logical states have disjoint support, it is much smaller than for transmon or fluxonium devices at a comparable coupling.

## Sweeping the coupling capacitance

The coupling capacitance sets g and also renormalizes each qubit's charging energies, so qubit 1's levels move as `C_c` grows.
Inverting `g = 8 E_C[θ1, θ2]` for `E_Cc` gives a sweep in g; `previous=` starts each point from the last solution:

```@example tzp
a = 1 / θ.E_Ctheta
E_Cc(g) = (4 - g * a) / (g * a^2)                  # inverts g = 4 C_c/((a + C_c) a), C = 1/E_C

small, small_qubits = tree(12; root_keep=4)                # only qubit 1's levels are read
gs = range(0.002, 0.04; length=40)
levels = let prev = nothing
    map(gs) do g
        s = materialize(small, spec, merge(θ, (E_Cc=E_Cc(g),)); previous=prev)
        prev = s
        E = energies(s, small_qubits[1])
        E[1:11] .- E[1]
    end
end

fig = Figure(size=(700, 450))
ax = Axis(fig[1, 1]; xlabel="g (GHz)", ylabel="E − E₀ (GHz)", title="qubit 1 with the coupling capacitances")
for n in 1:11
    lines!(ax, gs, getindex.(levels, n); color=n in (8, 9, 10) ? :black : :gray60)
end
vlines!(ax, [8EC[1, 3]]; color=:black, linestyle=:dash)
text!(ax, 0.0215, 7.5; text="|7⟩, |8⟩", align=(:center, :bottom))
text!(ax, 0.0105, 8.35; text="|8⟩, |9⟩", align=(:center, :bottom))
ylims!(ax, 5.5, 9.2)
save(joinpath(figdir, "soft_zero_pi_crossing.png"), fig; px_per_unit=2); nothing # hide
```

![Qubit 1 levels against the coupling g](soft_zero_pi_crossing.png)

Levels `|8⟩` and `|9⟩` cross near g ≈ 0.01 GHz and `|7⟩` and `|8⟩` near g ≈ 0.02 GHz, as in the paper; the dashed line marks the operating point g ≈ 0.031 GHz.
