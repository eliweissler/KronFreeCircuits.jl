Getting started

This page solves a transmon, then two coupled transmons, and shows how to read energies, operators and states. The specs come from circuit-quantization; Building circuits explains how to make your own. The example specs ship with the package, in its test/fixtures/generated directory; change to it to run the examples in this documentation as written:

cd(joinpath(pkgdir(KronFreeCircuits), "test", "fixtures", "generated"))

One transmon

A spec lists the circuit's modes and parameters:

using KronFreeCircuits

spec = load_spec("transmon.json")
spec.modes, spec.parameters
(KronFreeCircuits.ModeSpec[KronFreeCircuits.ModeSpec(:varphi_1, :c)], [:E_C, :n_g, :E_J])

The transmon has one compact mode, varphi_1. A tree with a single leaf describes how to solve it: the mode's basis, how many states to keep, and which operators (ports) to form in the kept eigenbasis.

leaf = Node([:varphi_1 => ChargeBasis(30)]; keep=lowest(6), ports=[(:varphi_1, nport())])
θ = (E_J=30.0, E_C=1.2, n_g=0.25)
sys = materialize(leaf, spec, θ)
energies(sys)
6-element Vector{Float64}:

  -6.162750422806813
   8.000666020855807
  20.215054846222394
  29.873540897381048
  39.81708168386945

ChargeBasis(30) holds the charges -30..30. materialize solves the tree at the parameter values θ, in GHz, and returns a System. The kept charge operator is a 6 × 6 matrix:

n = port(sys, :varphi_1, nport())

Two coupled transmons

Two transmons coupled through their charges have a tree with one leaf per transmon and a parent that couples them. Each leaf keeps its lowest 8 states, and the parent diagonalizes the 64-dimensional product of the kept states:

spec = load_spec("two_transmons.json")
θ = (E_J1=30.0, E_C1=1.2, n_g1=0.25, E_J2=25.0, E_C2=1.0, n_g2=0.0, g=0.3)

transmon(i) = Node([Symbol("varphi_$i") => ChargeBasis(30)]; keep=lowest(8))
root = Node([transmon(1), transmon(2)]; keep=lowest(20), ports=[(:varphi_1, nport())])
sys = materialize(root, spec, θ)
energies(sys)[1:6] .- energies(sys)[1]
6-element Vector{Float64}:
  0.0
 13.031340595289304
 15.684737015138182
 24.77603350042411
 28.652380131029982
 29.91528143571314

Each node solves with Auto() unless told otherwise; here every node is small, so Auto() picks exact dense diagonalization. Solvers lists the others and when to use them.

Reading states

A dressed state of the parent is a superposition of products of its children's kept states. decompose gives that content for dressed state 2 (Julia indices from 1), largest first:

decompose(sys, root, 2)
2-element Vector{Pair{Tuple, Float64}}:
 (1, 2) => 0.9955934890270138
 (2, 1) => -0.0925321401105129

dressed_state_string prints the same state for a paper or a log, with physics indices that start at 0, both for the dressed state and for each child's states:

println(dressed_state_string(sys, 1))   # the same state as decompose(sys, root, 2)
println(dressed_state_string(sys, 2))
|ψ₁⟩ = 0.996|0,1⟩ − 0.093|1,0⟩
|ψ₂⟩ = 0.996|1,0⟩ + 0.093|0,1⟩

dressed_index goes the other way, from a bare product label to the dressed state that overlaps it most:

dressed_index(sys, root, (2, 1)), dressed_index(sys, root, (1, 2))
(3, 2)

The labels are 1-based indices into each child's kept states, so (2, 1) is the first transmon's first excited state with the second transmon in its ground state.

A child's own results are read by passing the child node:

energies(sys, root.children[1]) .- energies(sys, root.children[1])[1]
8-element Vector{Float64}:
  0.0

 51.700213089807534
