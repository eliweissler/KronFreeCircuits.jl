KronFreeCircuits.KronFreeOperator — Type
KronFreeOperator(dims, terms; constant=0.0, block_capacity=1, on=Array, hermitian=true)

H = Σ_t c_t ⊗_k A_{t,k} + constant * I on the tensor-product space with axis sizes dims (axis 1 fastest), applied without forming Kronecker products. Terms whose factors are all DiagonalOp are fused with constant into one state-shaped vector H.diag, applied by a single broadcast; the remaining terms are kept in H.terms as records holding, per factor, (axis, op, data) with data the array the application reads. The fused terms are kept in H.diagterms (the constant as a zero-factor term) for introspection; the application reads only H.diag. Derived quantities (sparse(H), gershgorin_bound, separable_eigenbases, product_seed) are computed on request and memoized; nothing is assembled at construction. Every array H owns (diag, factor data, scratch) is stored on on at construction (adapt(on, …); the scratch is allocated like the adapted diag). DenseOp factors are applied as ITensor contractions over H.inds (one index per axis) and H.blockinds (one block-axis index per width, cached on first use); the other factors keep their kernels and broadcasts. Two work buffers reserve block_capacity columns at construction. Calls reuse their active prefix, growing storage only when the requested block exceeds capacity. Reserve the solver's maximum block width before iteration to avoid state-sized scratch reallocations. mul!(y, H, x) writes into caller-owned output; H * x allocates its output on on. The scratch belongs to H, so simultaneous applications require separate operators/workspaces.

ishermitian(H) returns hermitian, a claim the constructor stores without checking: callers are responsible for building terms that sum to a Hermitian operator when they leave it true (every Hamiltonian), and set it false for one that is not (a port such as e^{iφ}, see port_operator).

KronFreeCircuits.Solver — Type
Solver

The abstract type of node eigensolvers: Auto (the default), Dense, Lanczos, LOBPCG, ShiftInvert and ChebyshevFilter. The contract below is what a user-defined solver implements; a user solver needs only solve.

  • KronFreeCircuits.solve(s, H, m; X0=nothing) -> (E, V): the lowest m eigenpairs of the Hermitian operator H::KronFreeOperator, with E::Vector{Float64} ascending and V::Matrix{eltype(H)} on the host (size(H, 1) × m, orthonormal columns, V[:, j] the eigenvector of E[j]). Every true residual ‖H V[:, j] − E[j] V[:, j]‖ must be below the solver's tolerance, checked with H itself before returning (an inner Krylov tolerance is not an acceptance criterion). materialize calls solve(s, H, m) for every solver except LOBPCG, which receives the previous block (nothing or m columns) as X0; a user solver may accept X0=nothing but need not.
  • KronFreeCircuits.storage(s) (optional, default Array): the array type materialize builds H on; a device solver returns its device array type, and still returns E and V on the host.
  • KronFreeCircuits.resolve(s, info) (optional, default s): the solver that actually runs, given info = (; isleaf, dims, m); this is how Auto picks a solver by node shape.

H is real (eltype(H) <: Real) at a node that is real by structure, so a user solver must accept real operators and return real V for them.

What H provides: mul!(Y, H, X) and H * X on vectors and blocks of any width on storage(s); size(H) and eltype(H); and, on the host, computed when asked for and memoized on the operator, diagonal(H), sparse(H; maxnnz) (from SparseArrays), gershgorin_bound(H), separable_eigenbases(H) and product_seed(H, k). On Array storage Matrix(H) forms the dense matrix. A node with compute == 0 (all eigenpairs) accepts only a solver that is, or resolves to, Dense. The Node constructor exempts only Auto from this check, so a user solver with a custom resolve that resolves to Dense must set compute explicitly.

source
KronFreeCircuits.solve — Function
solve(solver, H, m) -> (vals::Vector{Float64}, vecs::Matrix{eltype(H)})

Eigenpairs of the Hermitian operator H, ascending. Dense returns the lowest m pairs, or all when m == 0 or m >= size(H, 1); Lanczos, LOBPCG and ShiftInvert return the lowest m (ShiftInvert with an interior shift: the m nearest it). See Solver for the contract a user-defined solver implements.

source
KronFreeCircuits.resolve — Function
resolve(solver, info) -> Solver

The solver that diagonalizes a node, given its solver field and info = (; isleaf, dims, m): whether all its children are bases, its product dimensions, and the number of eigenpairs requested. Every solver resolves to itself; Auto resolves by the node's shape (see its docstring). materialize resolves each node once, before building its operator, and builds the operator's storage and scratch from the resolved solver.

source
KronFreeCircuits.gershgorin_bound — Function
gershgorin_bound(H::KronFreeOperator) -> Float64

A rigorous upper bound on the largest eigenvalue of the Hermitian operator H: maximum(real(H.diag)) + Σ_t |c_t| Π_k infnorm(A_{t,k}) over the terms kept in the contraction sum (plus maximum(abs ∘ imag, H.diag), zero for a Hermitian fused diagonal). It holds because H − Re(diag) is Hermitian, so its 2-norm is at most its ∞-norm, and the ∞-norm of a Kronecker product is the product of the factors' ∞-norms. Memoized in H.gershgorin.

source
KronFreeCircuits.separable_eigenbases — Function
separable_eigenbases(H::KronFreeOperator) -> (; U, λ)

Per axis k, the eigendecomposition U[k] * Diagonal(λ[k]) * U[k]' of the d_k × d_k sum of every term with exactly one factor, on axis k (c_t · dense(A), terms fused into the diagonal included); the constant H was built with is added to axis 1. Terms on two or more axes, diagonal or not, are coupling and are ignored. An axis whose single-axis sum is diagonal (in particular one with no single-axis term) keeps the identity as U[k] and the diagonal, unsorted, as λ[k]; otherwise λ[k] is ascending from eigen!. A single-axis sum that is not Hermitian to round-off means H is not Hermitian and throws ArgumentError. Memoized in H.separable; host data.

source
KronFreeCircuits.product_seed — Function
product_seed(H::KronFreeOperator, k::Integer) -> Matrix

k orthonormal product states on the host, of size (prod(dims), k): the columns ⊗_a U_a[:, i_a] (axis 1 fastest) of separable_eigenbases(H) with the k smallest summed energies Σ_a λ_a[i_a] (partialsortperm over the length-prod(dims) Kronecker sum of the λ_a, which is smaller than the result), each column built by kron of the small per-axis vectors. When every U_a is the identity (a branch, whose axes are already eigenbases) the columns are the unit vectors of the k smallest entries of the full diagonal _full_diagonal(H) (the fused diagonal plus the diagonals of the kept terms, which include diagonal matrices that are not DiagonalOps and the port couplings).

KronFreeCircuits.SelectionContext — Type
SelectionContext(energies, vectors, ports, previous[, reference])

What a selection rule may inspect after a node is diagonalized: the computed energies, the eigenvector columns vectors, the port matrices in the eigenbasis keyed by (mode, port), previous, the node's previous MaterializedNode (or nothing), and reference, the previous kept vectors expressed in the current product basis (or nothing). materialize passes as reference the previous kept vectors transported through the children's physical overlaps, so that reference' * vectors are physical overlaps even when the children were re-diagonalized. KronFreeCircuits.Derivatives — Type
Derivatives

The derivatives of a materialized tree, returned by derivatives and read through energies, eigenvectors and port with a parameter name (first order) or two (second order). sys is the differentiated System, wrt the parameters (in the order processed), order the order, and mixed the mixed pairs of second order, each as _pairkey orders it. first[x] is the root's first-order derivative data along x (a NodeDerivative, the children's nested in it), or nothing when nothing in the tree depends on x. With order = 2, second[_pairkey(x, λ)] is the root's second-order data along the pair (x, λ), for x == λ each parameter of wrt and for x ≠ λ each pair of mixed, likewise nested, or nothing when no node depends on both. blocks holds the near-degenerate blocks, NearDegenerateBlocks, read through blocks. boundary holds the selection-boundary records (; node, parameter, kept, unkept, detuning, coupling): a kept state (kept, a column of the node's vectors) close to an unkept computed state (unkept, its index among the node's computed pairs), with coupling NaN when it was not computed; parameter is the parameter of a first-order pass, or the pair _pairkey(x, λ) of a second-order pass, which records only clashes (an exact degeneracy with a coupling). linear_solves holds one record (; modes, columns, iterations, residual, from_start, at_floor, floor_residual) per linear solve on the complement of a node's computed states: residual the largest true residual, relative to the column's complement part ‖Q (∂H/∂x) ψ_j‖, of the columns that met lintol; from_start the columns converged from the start (no solve); at_floor the columns that stopped at the round-off floor, and floor_residual their largest true residual relative to the whole right-hand side ‖(∂H/∂x) ψ_j‖.

KronFreeCircuits.NearDegenerateBlock — Type
NearDegenerateBlock

A group of kept states of one node whose second-order Taylor expansion along parameters is not trusted over the caller's scale, with the block's effective Hamiltonian; returned by blocks. parameters is (x,) for a parameter, or the mixed pair (x, λ) (ordered by name) for the union of the blocks of x, of λ and of the mixed second-order pass. states are the kept-state indices at node (columns of its vectors), increasing, and energies their energies. A pair (i, l) of kept states is flagged along x when |⟨ψ_l|∂H/∂x|ψ_i⟩| δx > r |E_i − E_l| with a nonzero coupling (δx the scale of x), or when it is an exact degeneracy (a detuning within degenerate_tol) with a nonzero coupling, at first order or, through other states, at second order; a block is a connected component of the flagged pairs. detuning is the smallest |E_i − E_l| and coupling the largest coupling among the flagged pairs: the first-order matrix element |⟨ψ_l|∂H/∂x|ψ_i⟩|, or for a pair flagged by a second-order clash the second-order one, the overlap of ψ_l with the second-order right-hand side of ψ_i. For a block flagged in more than one way coupling is the largest of quantities that may have different units (first-order couplings to different parameters, a second-order matrix element for a pair flagged by a second-order clash): it is for reporting, not for arithmetic. exact is true when a flagged pair is exactly degenerate: the per-state derivatives of its states are NaN, and the block's effective Hamiltonian is what is defined. order is the order of the effective Hamiltonian in the displacement (the order of derivatives). H1[x] is ⟨ψ_b|∂H/∂x|ψ_b′⟩ over the block's states, for each parameter x of parameters. H2[(x, y)] (each pair of parameters, by _pairkey; empty when order == 1) is ⟨ψ_b|∂²H/∂x∂y|ψ_b′⟩ + F^{xy} + F^{yx}, with F^{xy} = ½ (M^{xy} + (M^{yx})†), M^{xy}[b, b′] = ⟨(∂H/∂x) ψ_b|Y^y_{b′}⟩ and Y^y_{b′} = Σ_{l ∉ B} ψ_l ⟨ψ_l|∂H/∂y|ψ_{b′}⟩ / (E_{b′} − E_l) over every state of the node outside the block, kept or not: the outside states folded in to second order in the displacement. A block state exactly degenerate with an unkept state it couples to (a selection-boundary record) makes these pieces NaN. tr(H1[x]) and tr(H2[(x, x)]) are the block-invariant sums of the first and second derivatives of the block's energies, which exist even when the per-state derivatives are NaN. See block_levels.

KronFreeCircuits.differentiate — Function
differentiate(c::Coefficient, x::Symbol) -> Coefficient

The derivative ∂c/∂x for real parameters, by symbolic differentiation of c.ex. The result's expression is lightly simplified as it is built: zero terms, unit factors, f^1, f^0 and 1^g are removed, a zero factor makes a product zero, and an operation on numbers alone is evaluated where that does not change its value. It is a constant coefficient (a number expression, zero when c does not depend on x) when it simplifies to a number. sign(f) differentiates to zero, except that an ArgumentError is thrown when f depends on x and may be complex. Second derivatives are two calls.

KronFreeCircuits.node_timings — Function
node_timings(f) -> (result, records)

Run f() (typically a materialize call) and return its result with one record per node solved inside it, in the order solved (children before their parent, so the root is last). Each record is a named tuple: modes (the node's modes), dims (its product-basis axis sizes), dim (their product), compute (eigenpairs asked for), kept, solver (the resolved solver's type name), real (real arithmetic), operator_seconds (building the node's operator from its children's ports and its terms), solve_seconds (the eigensolve), assemble_seconds (selection, phase fixing, and forming the ports and joint ports its ancestors need), and iterations, n_matvec and warm (a warm-started initial block) for a LOBPCG node, nothing otherwise. Given systems and basis children are not solved and have no record. Times are wall clock (time_ns); a device solve returns host arrays, so its time includes the device work.

KronFreeCircuits.edge_weight — Function
edge_weight(solved::MaterializedNode) -> Float64

The amplitude of the lowest kept state of a solved single-mode leaf on the ends of its PhaseGrid; its square is the state's weight (probability) there. It is measured as the PhaseGrid edge warning of materialize measures it: the 2-norm of the state's entries on the first order ÷ 2 and the last order ÷ 2 grid points together. The warning fires for a kept state whose measure exceeds 1e-6. A leaf on any other basis has nothing at an edge and gives 0.0. A node that is not a single-mode leaf is an ArgumentError.

KronFreeCircuits.augment — Function
augment(parent, terms, θ, child, bare, U, report) -> AugmentedChild

The child child of parent presented through the orthonormal basis U on its own product space. bare is the child's bare solve (bare_child), whose children span the product space and are not solved again. It must be the solve on which the columns of U are expressed: for vectors from mean_field_solutions, the same object that was passed to it as bare (another solve of the child can have other kept vectors in its children, and U would then be read on another product basis without any error). The child's bare operator H, on its own terms only and in complex arithmetic, is projected to U' * H * U and diagonalized densely. Every column is kept, so the child presents size(U, 2) states, and its compute and keep settings do not apply. The kept vectors are U * W with W the eigenvectors of the projection, with the child's phase convention and the ports and joint ports of child_keys(parent, terms, child). report is stored with the result, as are a copy of U and θ. The result is used as built, at these terms and θ. materialize refuses it at a θ that differs from this one in a parameter the child's bare terms depend on; it does not check the terms themselves, nor the parameters of the terms inside a branch child (those of its bare solve), and it is the caller's job to rebuild the child when they change. A union basis that is not made of eigenvectors of the child can trigger the parent's "heavy hybridization" phase warning, which reports on the phase convention and is not an error. An ArgumentError is thrown when bare is not a solve of child, when U does not have one row per state of the product space or has no column, and when U' * U differs from the identity by more than 1e-8.

source
KronFreeCircuits.union_basis — Function
union_basis(sources; m, drop = 1e-6, allow_fewer = false) -> (U, report)

Merge sources, a vector of BasisSource, into one orthonormal basis U of m columns. The merge is level by level: the first offered column of each source in the order given, then the second of each, and so on, until m vectors are accepted. A candidate is orthogonalized against the accepted vectors by classical Gram–Schmidt applied twice, and accepted when the norm of the remainder is above drop; it is then normalized. A source that is capped or windowed stops offering at its limit, so an uncapped source fills the remainder. report is a UnionReport counting, for each source, the vectors accepted and the vectors offered and rejected. Ending with fewer than m vectors is an ArgumentError that prints the report, unless allow_fewer = true, which returns the vectors found.

BasisSource(label, vectors, energies; cap = nothing, window = nothing)

One source of vectors on a child's own product space, for example the lowest mean-field states of the child in one self-consistent solution. The columns of vectors are unit vectors, lowest state first, and energies holds one energy per column. At most cap columns are offered, and only the columns whose energy is within window of the first energy are offered. The arrays are copied and converted to ComplexF64 and Float64.

KronFreeCircuits.AugmentedChild — Type
AugmentedChild

A child presented to its parent through a basis of its own choosing, the union basis U, instead of its ordinary solve. node is the child, and basis is U on the child's own product space, one orthonormal column per vector. terms are the child's bare terms, those route places at the child itself, with no mean-field terms. θ is the parameter point given to augment, at which solved was formed; materialize refuses the child at a θ that differs from it in a parameter that terms depend on. solved holds the child's bare operator projected on basis and diagonalized: its vectors are basis * W, lowest energy first, all size(basis, 2) of them. solved forms the ports and joint ports that its parent's terms need inside the child, as child_keys lists them. report is the UnionReport of the merge that built basis. Pass it to materialize with augmented to use it in place of the child's ordinary solve.

KronFreeCircuits.charge_port — Function
charge_port(sys, mode) -> Matrix{Float64} or Matrix{ComplexF64}

The physical charge n of mode in the kept eigenbasis of the leaf that holds it, V′ n V, computed on demand from that leaf's kept vectors, in the port's natural type (as port): real for a real-character n (a ChargeBasis mode of a leaf in real arithmetic), complex for a grid's imaginary n or on a complex node. source
KronFreeCircuits.operator — Function
operator(sys, node=root) -> KronFreeOperator

The Hamiltonian of node in its product basis at sys.θ, rebuilt from the materialized children exactly as materialize built it (the root's includes the constant; its scratch and storage follow the node's solver, as resolved by materialize); it is real exactly when the node was materialized in real arithmetic. An ancestor of an augmented node gets the operator it was diagonalized with, on the augmented child's states. An augmented node itself throws an ArgumentError: its stored states diagonalize its bare operator projected on its union basis, not an operator on its product basis, and augmented gives the AugmentedChild with that basis and the bare terms. A node inside an augmented node is the one of the bare solve given to augment, and its operator is rebuilt at sys.terms and sys.θ, which are the ones of that solve only when the caller kept them the same.

KronFreeCircuits.Experimental — Module
KronFreeCircuits.Experimental

Features that work and are tested but whose interface is not settled, kept out of the main export list:

  • Born–Oppenheimer reduction (bo_surface, fit_surfaces, slow_spec, …; experimental/bo.jl): solve a fast subsystem on a grid of the slow coordinates and hand the slow coordinates an effective potential.
  • Mean field (self_consistent, mean_field_solutions, mean_field_terms, …; experimental/meanfield.jl) and basis augmentation from its solutions (mean_field_augment; the augmentation itself, KronFreeCircuits.augment, is core).
  • DMRG of the root (dmrg_levels), a thin wrapper on ITensorMPS, available once ITensorMPS is loaded.

using KronFreeCircuits.Experimental brings these names into scope.

BOSurface

KronFreeCircuits.fourier_coefficients — Function
fourier_coefficients(s::BOSurface; band::Integer=1) -> (a0, a, b)

The discrete Fourier coefficients of band band of a surface on a uniform periodic grid (M points, spacing 2π/M): U(θ) = a0 + Σ_k a_k cos kθ + b_k sin kθ, exact at the grid points, with a0 the mean, k = 1..⌊M/2⌋, a_k = (2/M) Σ U_j cos kθ_j, b_k = (2/M) Σ U_j sin kθ_j, and for even M the Nyquist harmonic with the factor 1/M instead of 2/M. Since cos(Mθ_j/2) and sin(Mθ_j/2) are both (-1)^j times a constant, the Nyquist pair reproduces the data exactly for any grid start (for the default start b_{M/2} is zero up to rounding). Throws ArgumentError if the slow mode is not compact or the grid is not uniform and periodic.

KronFreeCircuits.slow_spec — Function
slow_spec(s::BOSurface; band::Integer=1, K=nothing, tol=nothing) -> (spec::Spec, dropped::Float64, metadata::Dict)

The one-mode spec of the slow mode of s: E_C and n_g from the promoted spec, no inductive terms, the mean of the surface as the constant, and for each kept harmonic k the cosines -a_k cos kθ and -b_k cos(kθ - π/2) (entries with zero energy are omitted). Harmonics k ≤ K are kept; with tol instead, the smallest K whose dropped amplitude Σ_{k>K} hypot(a_k, b_k) is at most tol; with neither, all of them. dropped is that amplitude sum for the harmonics left out. K and tol are mutually exclusive, and K at or above the highest harmonic keeps all.

Every parameter in s.θ that s.promoted.fast depends on is substituted by its value in E_C and n_g (the surface assumed it); the rest stay free parameters of the returned spec.

metadata is the spec's provenance, ready for save_spec: metadata["_bo"] records the source spec (as a JSON object), the slow mode, the band, the substituted and surface parameters (as in fit_surfaces), the slow grid, the number of harmonics kept and the dropped amplitude; metadata["_generator"] records the package version. Callers add numerical settings such as fast-leaf bases and cutoffs before saving. Two-name destructuring, spec, dropped = slow_spec(s), still works.

KronFreeCircuits.fit_surfaces — Function
fit_surfaces(surfaces::AbstractVector{BOSurface}, model::AbstractVector{<:Pair}; band::Integer=1) -> BOFit

Fit band band of surfaces (Born–Oppenheimer surfaces of one slow mode at different parameter samples) to a linear model and return the fitted constants with the reduced one-mode spec they define.

A model is [key => ["expr", ...], ...]. Each expression is a scalar expression of the source spec's parameters (the Coefficient grammar), and each key names a slow basis function b(s); the fitted surface is U(s; params) = Σ c_i h_i(params) b_i(s) with unknown constants c_i, one per (key, expression) pair. The keys are chosen so that each constant multiplies a spec entry directly:

keyb(s)reduced-spec entry that gains c h(params)slow mode type
:constant1constantany
(:cos, k)-cos(k s)cosine energy, omega = [k], offset = 0any (k an integer on a compact mode)
(:sin, k)-sin(k s)cosine energy, omega = [k], offset = -π/2any (k an integer on a compact mode)
:xsflux_linearextended or harmonic
:x2s²E_L, as 2 c h (the form is ½ E_L s²)extended or harmonic

All data points (every surface, every grid point) enter one least-squares solve, A \ y (QR). stderr[i] = sqrt(σ² (AᵀA)⁻¹ᵢᵢ) with σ² = RSS/(n - p); it is NaN when n == p. On a compact slow mode a harmonic above ⌊M/2⌋ (M the smallest grid) would alias onto a lower one and is refused. Fewer points than constants, a rank-deficient design matrix (including a basis function that vanishes on every grid point), or an unknown key is an ArgumentError.

The surfaces must share one source spec and slow mode, and may differ only in the parameters that occur in the model's expressions (the fitted-over parameters); every other entry of their θ must agree exactly, else an ArgumentError names the parameter. The reduced spec's parameters are the fitted-over ones and those of E_C[s,s] and n_g[s] that the fast spec does not depend on; every other parameter of E_C[s,s] and n_g[s] is substituted by its shared fixed value, as in slow_spec. Parameters held fixed while computing the surfaces therefore never remain free in the reduced spec. metadata["_bo"] records the source spec (as a JSON object), the slow mode, the substituted parameters (values written into the reduced spec as numbers), the surface parameters (every value held fixed while computing the surfaces, substituted or not), each surface's slow grid and fitted-over values, the model, constants, standard errors and residuals; metadata["_generator"] records the package version. The residuals are the reduced spec's truncation measure: how far the model is from the computed surfaces. A surface does not know the fast leaf that produced it, so callers add numerical settings (fast-leaf bases and cutoffs, solver tolerances) to the metadata before saving, under their own _-prefixed keys or inside _bo.

KronFreeCircuits.mean_field_terms — Function
mean_field_terms(parent, terms, θ, child, others; outside=nothing) -> Vector{Term}

The extra terms for child: each straddling term of parent reduced to the factors on child's modes. Its coefficient at θ is multiplied by the expectation value, from others, of each other child's group of its factors (one key per child). others maps each other child that a term touches to its table. Terms with the same factors are merged by adding their coefficients, and a merged term whose coefficient is zero is kept. A straddling term that does not touch child contributes nothing. The returned terms have constant coefficients.

A term with a factor on a mode outside parent is absent when outside is nothing. When outside is given it must hold the expectation value of each such term's outside factors (as one key), which is one more factor of the coefficient.

MeanFieldChild

KronFreeCircuits.MeanFieldSolution — Type
MeanFieldSolution

A self-consistent mean-field solution of the children of a node: each child solved in the mean field of the others. energy is the product energy of the last iteration, and children holds every child's MeanFieldChild: its states are those of the final solve at the final tables, and its tables and bare energy those of the last iteration (details below). start is where the run began: nothing (delocalized), a displacement Dict, or :warm when the run was started from another solution. A warm-started solution keeps no reference to the solution it came from. converged is false when the run stopped at its iteration limit, and iterations is the number of iterations run. The solved and terms of each child are those of a final solve in the mean field of the final expectation values, made after the last iteration and not counted in iterations. KronFreeCircuits.self_consistent — Function
self_consistent(parent, terms, θ, bare; start=nothing, tol=1e-11, maxiter=300, mixing=0.5, constant=0.0,
                state=1, weights=nothing, outside=nothing) -> MeanFieldSolution

The self-consistent mean-field loop over the children of parent, with bare mapping each child to its bare_child. Each iteration solves every child with mean_field_child from the tables of the previous iteration, then computes the product energy from the new tables and bare energies. After the energy has risen (by more than 1e-12) twice, every later iteration replaces the new tables and bare energies by mixing times the new plus 1 - mixing times the previous ones. The run converges when |E - E_prev| < tol * max(1, |E|) and no table entry changed by sqrt(tol) or more. The rise threshold 1e-12 is absolute and the energy test switches from absolute to relative at |E| = 1, so both assume energies of order one in the spec's unit (GHz); in another unit, scale tol with it. A run that reaches maxiter iterations is returned with converged = false. When the loop ends, converged or not, every child is solved once more with mean_field_child from the final tables, the ones the last energy was computed from; this solve is not counted in iterations. The solution holds the energy of the last iteration and, for each child, a MeanFieldChild whose solved and terms are those of that final solve, so solved holds the child's states in the mean field of the final expectation values. Its expectations and bare_energy are the ones the energy was computed from: those of the last iteration's solve (under mixing, the mixed values), so product_energy of them reproduces energy. start is nothing (delocalized), a Dict{Symbol,Float64} of displacements (see pinned_expectations), or a MeanFieldSolution whose tables it continues from. A displacement that names a mode not under parent is an ArgumentError, and a mode it leaves out has displacement zero. The returned solution's start is the given start, except that a warm start is recorded as :warm, so that no chain of earlier solutions is kept alive. constant is added to the product energy, and state, weights and outside are passed to mean_field_child.

KronFreeCircuits.mean_field_solutions — Function
mean_field_solutions(parent, terms, θ; starts=default_starts(parent), distinct=1e-3, bare=nothing, kwargs...) -> Vector{MeanFieldSolution}
mean_field_solutions(parent, spec::Spec, θ; kwargs...) -> Vector{MeanFieldSolution}

Run self_consistent from every start in starts, with the bare solve of each child formed once and shared, and return the distinct solutions, lowest energy first. A solution is kept when, against every solution already kept, some table entry of some child differs by more than distinct. Ties in energy keep the order of starts, and runs that did not converge take part like any other. bare, when given, is a dictionary (an IdDict keyed by node) holding the bare solve (bare_child(parent, terms, θ, child)) of every child of parent, used instead of solving them here; a missing child, or a value that is not a solve of its child, is an ArgumentError. The solutions' states are coordinates on the children of these bare solves (for a branch child, on the kept states of its own children). A caller who goes on to augment should therefore form bare once, pass it here, and give augment the same bare solves: solving a child again can give its children other kept vectors (a randomly started solver, or another phase choice), and the solutions' states would then be read on another product basis. The remaining keywords are passed to self_consistent. The second form takes the terms from circuit_terms(spec) and constant from constant_term(spec) at θ.

KronFreeCircuits.mean_field_augment — Function
mean_field_augment(parent, spec, θ; m, window = 0.5, max_solutions = 4, bare = false, cap = nothing,
                   starts = default_starts(parent), allow_fewer = false, kwargs...)
    -> (; children, solutions, used, energy, unconverged)

The augmented children of every child of parent, built from its mean-field solutions: a convenience over the pieces that adds no behaviour of its own. It runs mean_field_solutions(parent, spec, θ; starts, bare, kwargs...), with bare the bare solves below, passing on every keyword not named here. It uses the solutions whose energy is within window of the lowest (inclusive), in order, at most max_solutions of them. window is an energy in the spec's unit, and its default 0.5 assumes energies of order one (GHz). It forms the bare_child of every child of parent once, before the loop, and passes them to mean_field_solutions as bare, so that the solutions' states, the union basis and augment share one product basis per child. For each child of parent, in order, it forms one BasisSource per used solution, labelled "solution <index>". That source holds the child's kept mean-field states in the solution, at most its first m, with their mean-field energies, and is limited by cap. With bare = true a last source, labelled "bare", holds the bare child's kept states with no limit. It merges the sources with union_basis(sources; m, allow_fewer) and presents the child through the result with augment. A used solution in which a child kept fewer than min(m, cap) mean-field states (m when cap is nothing) is an ArgumentError, raised before any union. children holds the AugmentedChild of each child of parent, in order, and solutions every solution found. used holds the indices in solutions of the solutions used. energy is the lowest product energy, solutions[1].energy. unconverged counts the used solutions that did not converge; they are used like the others, with no warning. An m < 1, a window < 0, a max_solutions < 1 and a cap < 1 are ArgumentErrors.

KronFreeCircuits.Experimental.dmrg_levels — Function
dmrg_levels(H::MPO; nlevels=1, weight, init=nothing, sweeps=nothing, observer=nothing, kwargs...)
    -> (; energies, states, variances, overlaps, observers)

The lowest nlevels eigenpairs of the MPO H by DMRG (ITensorMPS), a thin wrapper: the ground state by ITensorMPS.dmrg(H, ψ_init; kwargs...), then each excited state k by ITensorMPS.dmrg(H, [ψ_0, …, ψ_{k-1}], ψ_init; weight, kwargs...). Building H (and its site indices) from a tree is the caller's: any MPO works. Needs using ITensorMPS (a package extension); H and the states may live on the GPU (adapt(CuArray, H)), as ITensorMPS allows.

weight (required when nlevels > 1) is the penalty on overlapping the states already found: the excited solve minimizes ⟨ψ|H|ψ⟩ + weight Σ_j |⟨ψ_j|ψ⟩|². It must exceed the gap between the state sought and the states it should not fall back to, or a mixture with an earlier state can come out lower than the true next level; much larger than the spectrum's scale only slows convergence and costs precision. A few times the largest gap of interest, in the units of H, is the usual choice (for circuits in GHz with levels within a few GHz, 10 to 100). See the ITensorMPS documentation of dmrg (its "excited states" section) for the method. The returned overlaps let you check the choice: a weight that is too small shows as overlaps with earlier states that are not small.

  • init: the start of every level: nothing for a random MPS on the MPO's site indices (random_mps, bond dimension 10), an MPS, or a vector of state names that the sites' type defines (MPS(sites, init)); or a function k -> start returning one of these for level k (e.g. a product state for the ground state and random starts above it). On the GPU, return an MPS already on the device (the random and named starts are built on the CPU).
  • sweeps: an ITensorMPS Sweeps, passed to every dmrg call (else give nsweeps, maxdim, … as keywords).
  • observer: a function k -> observer (e.g. k -> DMRGObserver(; energy_tol=1e-10)), called once per level. A function, not an observer, because an observer keeps the energies it has seen: one shared by the levels would carry the ground state's history into the excited solves and stop them early. The observers are returned.
  • kwargs go to every dmrg call unchanged (nsweeps, maxdim, cutoff, noise, eigsolve_krylovdim, outputlevel, …).

Returns energies (in the order found, real, of the states themselves: dmrg's own value at k > 1 includes the penalty), states (the MPSs), variances (⟨H²⟩ − ⟨H⟩² per state, a convergence check in the units of H squared), overlaps (|⟨ψ_i|ψ_j⟩| for i ≠ j, a matrix with zeros on the diagonal) and observers (nothing per level when none was given).
